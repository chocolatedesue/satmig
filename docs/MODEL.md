# 形式化模型

本文件写清仿真器实现的模型：变量、公式、每条公式的出处，以及删掉了什么。
所有数值都可用 `python -m satmig all` 重算。

## 1. 星座与可用性

一个 Walker shell：`Q` 个轨道面 × `N` 颗星，面内成 ISL 环，面间同 slot 相连，
构成 `(plane, slot)` 环面格。

| 量 | 公式 | 550 km / 53° / 72×22 的值 |
|---|---|---|
| 轨道周期 | `T = 2π√(r³/μ)` | 5730.1 s |
| 无蚀临界角 | `β_crit = arcsin(R/r)` | 67.004° |
| 蚀占比 | `f(β) = (1/π)·arccos( √(1−(R/r)²) / cos β )`，`|β|≥β_crit` 时为 0 | β=0 → 0.3722 |
| 面 β 角 | `sin β = cos δ_s·sin i·sin(Ω−α_s) + sin δ_s·cos i` | −29.5°…+76.3° |
| 本影中心 | 反日向量投影到轨道面基底后的纬度论元 `atan2(−ŝ·q̂, −ŝ·p̂)` | 每面不同 |
| J2 节点漂移 | `−1.5·J2·n·(R/r)²·cos i` | 97.6° 时 +0.986°/天 |

卫星 `k` 的面内相位 `u_k(t) = u₀ + 2πt/T + 2πk/N`；当它与本影中心的角距小于
`π·f` 时处于蚀期。可用性因此是**确定性、周期、可提前一整轨解析求解**的——这就是
本工作相对地面 spot instance 的信息优势。

算力代理：`c_i(t) = 1`（受照）/ `c_e`（蚀期靠电池的降额档）。`c_e` 是假设，E3 专门扫它。

**独立对拍**：`β_crit = 67.0°`、`f(0) = 0.372`、`T = 95.5 min`、单 shell 内 β 跨度
到 `i + δ_s = 76.4°`，与 LAB-47 / LAB-58 / LAB-67 用 satellite.js + SGP4 得到的
数字一致。这四条在 `tests/test_orbit.py` 里是断言。

## 2. ISL 时延

一跳是弦长而非弧长：`chord(θ) = 2r·sin(θ/2)`。

| 方向 | 角距 | 弦长 | 时延 |
|---|---|---|---|
| 面内（沿轨） | `2π/N` | 1969.6 km | **6.571 ms** |
| 面间（跨面，赤道） | `(2π/Q)·cos φ` | 603.7 km | **2.014 ms** |

**跨面一跳只有沿轨的 1/3.26**（72 面 shell）。面数少时反转：12 面 shell 的跨面跳是
11.98 ms，比沿轨还贵。这个比值是第 2 号方案的全部依据。

## 3. 流水线：吞吐、时延、显存

模型 `L` 层切成 `P` 个 stage，stage 有序 ⇒ 宿主必须构成 ISL 图上的一条**路径**。

- 每 stage 服务时间 `t_s = L_s · t_layer / c_s`
- 1F1B 稳态吞吐 `R = M·b / [ (M+P−1)·max_s t_s + Σ hops ]`
  —— `P·M/(M+P−1)` 是它在均衡切分下的形状（LAB-47 用的形式）
- 单序列 TPOT `= Σ_s t_s + Σ hops`

**关键修正：hop 预算不是 `P` 跳，是往返。** 采样出的 token 必须回到 stage 0 才能
走下一步。1×P 的沿轨弧上，回程不是一跳而是 `P−1` 跳，所以每 token 付
`2(P−1)` 个沿轨跳。LAB-47 按 `P` 跳算，低估了约 2 倍。P=10 时：

```
沿轨 1×10 :  42.0 ms 计算 + 9×6.571 前向 + 9×6.571 回程 = 160.3 ms
蛇形 5×2  :  42.0 ms 计算 + (8×2.014 + 1×6.571) 前向 + 1×6.571 回程 = 71.3 ms
```

**偶数列的蛇形块把回程收成一跳**，这是它赢的机制，不是常数调优。

显存（PipeLive 原文公式）：

```
MaxBlocks(i, L) = ⌊ (M_i·u − L·W) / (L·P_blk) ⌋
B_shrink = min_i MaxBlocks(i)          可行性判据 B_used ≤ B_shrink
```

层切分必须是堆叠因子 `k` 的整数倍（PipeLive 第 6.2 节），所以 80 层 / k=4 只有
20 个可切单元，`P` 不整除 20 时切分不均衡、吞吐低于闭式值（`tests/test_perf.py`
里有这条的断言）。

24 GB 可用显存 × 0.9 下，`140 + 42.9 = 182.9 GB` 的模型要求 **P ≥ 10**。这是硬下界。

## 4. 迁移代价

| 机制 | 公式 / 常数 | 出处 |
|---|---|---|
| 触发时刻 | `T_start = min_i{ T_leave,i − ( Σ Size/B_ISL + T_ack + T_buffer ) }` | SCOPE Eq. 3 |
| 迁移优先级 | `V_c = λ_c / Size(c)` | SCOPE Eq. 2 |
| 协作可达 | `D(u,v) ≤ min(τ, D_ground(t))` | SCOPE Eq. 1 |
| 增量 KV 补丁 | 脏集几何收敛，直到 `T_sched − T_applied < τ` | PipeLive 6.3 |
| 切换 | 11.1 ms（纪元路由，pair-local）/ 555 ms（全局重建，约 50×） | CONNEX |
| 目标映射 | 加权二分图最大匹配（KM），边权=权重复用度 | SpotServe Device Mapper |
| 不迁移的代价 | `Loss = T_requeue + T_recompute` | Llumnix |
| 空闲度 | `F = (M − ΣV)/B` → 我们换成 `F_energy = t_到蚀期 + E_bat/P_cmp` | Llumnix 4.4.3 |

我们把 `T_leave`（离开服务区）换成 `T_eclipse_entry`（离开供能集合），把内容缓存
换成 stage 的 KV + 未驻留的权重分片。权重只读，走后台低优先级流，不占关键路径。

一次 stage 交接（P=10、KV 4.29 GB、100 Gbps）：

```
stop-and-copy KV     : 368 ms 传输 + 20 ack + 11.1 cutover = 399 ms
增量补丁（2 轮收敛）  : 残余 0.007 ms + 20 ack + 11.1 cutover = 31.1 ms   ← 12.8×
```

ISL 争用按每 slot max-min 公平：一条流在被 `n` 条流共享的链路上拿 `B/n`。
一次 `J` 跳的批量跳会把 `P` 份 KV 复用到同样的 `J` 条链路上，所以有效带宽退化到
`B/min(J,P)`——**批量化不是免费的**，跳距必须对着链路速率选（见 E6）。

## 5. 删掉了什么（以及后果方向）

| 删掉 | 后果 | 方向 |
|---|---|---|
| 姿态 / 帆板入射角 | 无功率时间被低估约 15 个百分点（LAB-67 实测） | **高估我们的成绩**，需注意 |
| 电池 SoC 动态（`c_e` 当常数） | "扛过去 vs 搬走"不是跨时段权衡 | E3 用扫参覆盖 |
| 半影 | 10–160 s 的瞬态不出现 | 影响很小 |
| 地球扁率、大气阻力、位保机动 | 长期相位漂移 | 3 轨窗口内可忽略 |
| prefill/decode 混合、请求到达过程 | 只报稳态 decode | 不报 TTFT |
| slot 内排队动态 | 交接在其起始 slot 内定价 | 10 s slot ≫ 0.4 s 交接 |
| 星地链路 / 用户侧 | 只做星上放置 | 与 SCOPE 的分工 |

第一条最重要：**本文所有"无功率"数字都只算几何蚀期，是下界。** 把姿态放回来会让
静态放置更差、迁移收益更大，所以本文的结论方向是保守的。
